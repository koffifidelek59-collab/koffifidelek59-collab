<a name="how"></a>
## 🧪 How I work

```text
Raw data
   ↓
Quality audit              →  every anomaly counted and justified
   ↓
Cleaning and modelling     →  documented and reproducible
   ↓
KPIs with explicit bases   →  no ambiguous indicator
   ↓
Statistical testing        →  effect size, not only p-values
   ↓
Dashboard and insights     →  from evidence to action
```

| Principle | In practice |
| :-- | :-- |
| **Reproducible** | Notebook, scripts and a README that let anyone rerun the results |
| **Documented** | Technical report in LaTeX, data dictionary, build guide |
| **Honest** | Limitations and non-causal readings stated in every project |
| **Decision-oriented** | Each insight linked to evidence, an action and an owner |
