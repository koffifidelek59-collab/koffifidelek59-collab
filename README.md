## 🧪 How I work

```text
Raw data
   ↓
Quality audit            →  every anomaly counted and justified
   ↓
Cleaning and modelling   →  documented, reproducible
   ↓
KPIs with explicit bases →  no ambiguous indicator
   ↓
Statistical testing      →  effect size, not only p-values
   ↓
Dashboard and insights   →  from evidence to action
```

My projects are documented end to end: a notebook, a technical report, a dashboard and a README that lets anyone reproduce the results.
