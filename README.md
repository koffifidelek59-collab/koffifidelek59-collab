## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Gear.png" width="32" alt=""/> How I work

```mermaid
flowchart LR
    A[(Raw data)] --> B[Quality audit<br/>every anomaly counted]
    B --> C[Cleaning & modelling<br/>documented, reproducible]
    C --> D[KPIs<br/>explicit bases]
    D --> E[Statistical tests<br/>effect sizes, not only p-values]
    E --> F[Dashboard & report]
    F --> G{{Decision}}
    style A fill:#0A66C2,stroke:#0A66C2,color:#fff
    style G fill:#0F766E,stroke:#0F766E,color:#fff
```

| Principle | In practice |
| :-- | :-- |
| 🔁 **Reproducible** | Notebook, scripts and a README that let anyone rerun the results, most of them one click away in Google Colab |
| 📝 **Documented** | Technical report in LaTeX, data dictionary, cleaning log, build guide |
| ⚖️ **Honest** | Limitations and non-causal readings stated in every project |
| 🎯 **Decision-oriented** | Each insight linked to evidence, an action and an owner |
